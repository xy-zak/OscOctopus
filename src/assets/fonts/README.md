# Fonts

`JetBrainsMonoNerdFontMono-{Regular,Bold}.woff2`: JetBrains Mono patched by
[Nerd Fonts](https://www.nerdfonts.com/) v3.5.1 ("Mono" variant: icons are single-width, so
everything stays on the character grid). Converted from the upstream TTFs with fontTools
(`fontTools.ttLib.woff2.compress`). Not subset, so any Nerd Font glyph works in widget labels.
